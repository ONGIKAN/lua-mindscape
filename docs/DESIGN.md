# Lua Mindscape 设计文档

> 本文件说明「Lua 思维可视化」的设计模型、trace 协议、视觉编码与正式版架构。
> English version: [DESIGN.en.md](DESIGN.en.md)。实现见仓库根目录的 `app.js`（原型）。

## 1. 问题与目标

用户要的是「一个 Lua 运行时，能实时显示 AST 语法树可视化，像看到大脑思考一样」。拆解后：

- **实时**：运行到哪一步，画面就走到哪一步（而不是先跑完再静态展示）；
- **语法树**：执行必须在树的结构上发生——节点被点亮的顺序就是求值顺序；
- **跨平台**：电脑 / 平板 / 手机都能用；
- **技术偏好**：Rust + Lua。

关键判断：**静态 AST 只是骨架，真正让人"看到思考"的是求值轨迹（trace）投影到 AST 上。**
AST 回答「程序长什么样」，trace 回答「程序此刻在想什么」。所以产品核心不是画树，
而是**把解释器的执行事件流实时投影到树、源码和栈帧上**。

## 2. 分层模型

```
源码 text
  │  parse（保留 span）
  ▼
AST（结构层）
  │  run（显式状态机，逐步产出事件）
  ▼
TraceEvent[]（轨迹层）
  │  seek / play（回放一个前缀，得到某一刻的状态）
  ▼
RuntimeState（状态层）→ 渲染（树 / 源码 / 栈帧 / 输出）
```

- **结构层**：每个节点有唯一 `id`、类型 `k`、源码区间 `span=[start,end)`、子节点列表。
- **轨迹层**：解释器不是一次性求值，而是「求值 + 发事件」，事件与节点 `id` 绑定。
- **状态层**：回放（把事件流前缀折叠成状态）得到当前节点、路径、栈帧、变量、已求值集合。
  渲染只读状态，不直接读解释器内部——**回放与渲染解耦**，因此拖动时间轴可以任意跳转。

## 3. Trace 事件协议

事件是纯数据（正式版用 Rust 定义，`ts-rs` 生成 TS 类型）。原型实现的事件：

| 事件 | 含义 | 关键字段 |
| --- | --- | --- |
| `ent` | 进入节点（开始求值/执行） | `id, k, span` |
| `cls` | 完成节点 | `id` |
| `val` | 表达式求值结果 | `id, v` |
| `set` | 变量 / 字段绑定或赋值 | `name, v, f` |
| `call` | 进入函数调用（新栈帧） | `id, name, nf, argc` |
| `ret` | 从函数返回（弹栈） | `id, name, v` |
| `iter` | 循环迭代 | `id, name, v` |
| `print` | 程序输出 | `text` |
| `end` | 程序结束 | — |
| `error` | 运行时错误 | `message` |

约定：事件总是产生于「某个栈帧 + 某个节点 + 某一时刻」，因此所有面板都能同步高亮。

## 4. 视觉编码

| 视觉元素 | 语义 | 设计理由 |
| --- | --- | --- |
| 节点方框 + 外环 + 光晕 | 当前节点 | 注意力只允许一个焦点；外环比填充底色更不遮文字 |
| 实线（靛蓝） | 根 → 当前节点的路径 | 表达「思路的来路」，是"思考"感的主要来源 |
| 节点右侧 `= 值` | 已求值结果 | 让数据流可见，而不只是控制流 |
| 颜色 | 栈帧 | 递归时同一时刻有多个上下文，颜色是唯一能同时编码的通道 |
| `×n` | 重复执行次数 | 循环/递归热点，一眼看出代价 |
| 表彩色圆点 | 对象身份 | 别名（两个变量指向同一张表）在纯文本里几乎不可见 |
| 代码行高亮 | 当前节点 / 外层栈帧 | 把树上的位置映射回源码，降低认知切换成本 |

视觉风格：浅色、方角、细边框、单一强调色（靛蓝），不使用渐变 / 霓虹 / 毛玻璃——
目标是"教学仪表盘"而不是"科技宣传片"。

## 5. 交互

- **时间轴优先**：可播放、暂停、单步、任意拖动；任何时刻状态都可完整重建。
- **树即时间轴**：点击任意节点 → 跳到该节点下一次被执行的事件。
- **代码即可编辑**：左侧源码区支持直接编辑并运行（原型用「高亮层 + 透明 textarea」叠层实现，
  保证语法着色与光标对齐）；解析错误就地显示，不破坏已有运行状态。
- **新建 / 导入**：`＋` 新建模板；`⇩` 选择或把 `.lua` 文件拖进代码区，读取后自动编译运行
  （失败就地显示解析错误）。
- **相机跟随（死区）**：当前节点在视口内圈时画面不动，接近边缘时才做最小幅度平移；
  点击节点 / 缩放 / `⤢` 才主动居中。拖动或缩放后暂停跟随，`⤢` 恢复；
  小屏上当前代码行会自动滚动到可见位置。
- **双语**：界面文案与节点类型名全部走 i18n 词典，`EN / 中` 即时切换并持久化。

## 6. 布局与渲染

- 三栏：源码（左）/ 语法树（中）/ 运行状态（右）；≤980px 变为单列堆叠。
- 树布局：经典 tidy tree（叶子按行占位，父节点取子节点中点），
  **兄弟子树之间留出额外间距**，避免不同父节点的分支在视觉上混在一起。
- 渲染：DIV 节点 + SVG 贝塞尔连线，只更新 class / 文本，不重建 DOM；
  代码层用 token span，高亮只是切换 class。
- 相机：直接计算 `translate + scale` 变换，跟随当前节点；节点位置为布局期算好的静态坐标。

## 7. 性能预算（正式版）

| 指标 | 目标 |
| --- | --- |
| 单步渲染 | < 4ms（只改变化节点） |
| 回放 | 拖动时最近 checkpoint + 重放 ≤ 数百事件 |
| 事件体积 | 每条 < 100B；长循环采样 / 折叠重复迭代 |
| 大树 | 只渲染可视区 + 默认折叠语句内部表达式 |

## 8. 正式版架构

- **解析**：Rust `full-moon`（lossless AST + span，支持 Lua 5.4）。
- **执行**：自研显式状态机解释器，**不插桩真实 Lua VM**（debug hook 只有行粒度，
  无法产生节点级事件）。语义兼容风险用 `mlua` 跑真实 Lua 做**差分测试**兜底。
- **通道**：WASM（浏览器 / 平板 / 手机）+ `ts-rs` 生成前端类型。
- **前端**：TypeScript + 轻量框架（Solid / Svelte 候选），渲染 SVG/DOM，必要时 Canvas。
- **打包**：Tauri 2（桌面 + 移动端复用同一前端）；Web 版可安装为 PWA（原型已具备）。

## 9. 测试策略

- **语义**：三示例输出断言（30 / 6 / 12）；随机程序与 mlua 差分对拍。
- **UI**：`tools/qa.mjs`（无头 Edge + CDP）验证布局、事件数、活跃节点、栈帧数、截图；
  手机 / 平板断点回归。
- **编辑器**：自定义代码运行、解析错误提示、localStorage 恢复。
- **i18n**：`?lang=en` 全量文案断言。

## 10. 已决策 / 待决策

已决策：
1. trace 是产品核心，AST 只是载体；
2. 自研显式状态机解释器 + 差分测试，而不是 hook 真实 VM；
3. Rust → WASM 为核心，Tauri 2 为桌面/移动外壳；
4. 浅色方角极简视觉，SVG/DOM 渲染。

待决策：
- 编辑器是否直接上 CodeMirror 6（正式版计划用）；
- 事件流的采样/快照策略参数；
- 是否支持 coroutine / 元表等高阶特性的分阶段范围。
